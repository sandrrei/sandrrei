## ☁️ Cloud-native, at home

- **[CV Online](https://github.com/sandrrei/cv-online)**: my CV as a service. One JSON file served as a web page, a JSON API, a terminal view and Prometheus metrics. NestJS + Docker.
- **Homelab**: a k3s cluster on Raspberry Pis (kube-vip, MetalLB, Longhorn), a self-hosted AI stack (Ollama, Open WebUI, n8n, Qdrant, SearXNG), Gitea, Nextcloud and Tailscale, all behind a MikroTik edge router.

## 🔧 Bringing things back to life

- **Biotrónica**: recovered a dead web platform from fragmented backups and rebuilt it with NestJS, HTTPS and its original Pascal desktop tools.
- **Meraki MR33 → OpenWrt**: desoldered NAND, new bootloader, free firmware.
- **Linux phones & tablets**: Ubuntu Touch on a Pixel 3 XL, Waydroid with Magisk, mainline Linux on an old Allwinner A13 tablet.
- **ESP32 on a washing machine**: schedule washes and pick programs from a web page.
